# Test Directory

This directory contains test utilities and scripts that are not directly used in the production application.

## Available Test Scripts

- `test_db.py` - Test MongoDB connection and operations
- `test_webhook.py` - Test the webhook functionality
- `test_whatsapp_message.py` - Test sending WhatsApp messages
- `test_appointment_webhook.py` - Test appointment booking functionality
- `verify_deployment.py` - Verify that the application deployed correctly
